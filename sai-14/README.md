# SAI — INCENSE & OBJECTS. (v14)

A standalone lightweight site. The catalogue screen is titled **STILL AIR.**

## Local preview

```bash
npm run dev
```

Open http://localhost:4173. Click the intro to enter. Use `Collection`, `Philosophy`, and `Bag` in the navigation.

## Verify / build

```bash
npm run check
```

`npm run check` validates JavaScript syntax, key content and local assets, and builds static output into `dist/`.

## GitHub / Vercel

Upload the **contents** of this project into the existing SAI-specific GitHub repository (not `1337tools`). In the *existing SAI Vercel project*, set Framework Preset `Other`, Build Command `npm run build`, Output Directory `dist`, Root Directory `./`.

## Notes

The checkout is a visual prototype, not a live payment system. Images are optimized WebP files already approved in earlier versions; no product artwork was edited in this release. See `CHANGELOG.md` and `QA_REPORT.md`.
