# SAI — Incense & Objects

Independent concept website for SAI. Built as a small static website (HTML, CSS and JavaScript). No external packages or font downloads required.

## Design

- Palette: `#dddde0`, `#ffffff`, `#000000`
- Typeface: `Andale Mono Regular`, followed by monospace fallback when the font is not locally installed
- Landing screen uses the original `Ресурс 2.png` exported as `public/assets/hero-logo.png` **without recreating the logo**
- Page transitions use blur / mist with reduced-motion support
- Includes Home, Collection, Philosophy, Bag and item detail modal
- Incense variants: Hinoki, Rice Smoke, Black Tea, Red Shiso, Yuzu Peel and Cedar Dust ($15 each)
- Incense Holder: $55
- Matches and journal have no assumed prices; journal artwork intentionally blank
- Shopping bag is an interactive demo and persists in browser localStorage; no real orders or payments

## Verify / build

```
npm run check
npm run build
```

The build creates `dist/`. You can deploy it directly to any static host.

## Deployment to Vercel without affecting 1337tools

1. Create **a new, separate GitHub repository**, such as `sai-incense-objects`; do not modify or push to the 1337tools repository.
2. Upload the files from this folder to the new repository. Do not include `dist/` (generated by build).
3. In Vercel, choose **Add New → Project → Import Git Repository** and select the NEW SAI repo.
4. Framework preset: **Other**. Build Command: `npm run build`. Output Directory: `dist`. Root Directory: `./`.
5. Deploy to a new Vercel project. **Do not connect the 1337tools project, its production domain or its environment variables.**
6. If you later add a custom domain to SAI, configure it only within the new SAI Vercel project.

## Product assets

Images in `public/assets/` are drawn from the SAI images already approved in this conversation. To replace a photo, keep the same filename or update its path in `public/app.js`.

## Known limitations

- Andale Mono is licensed commercial software and is **not bundled**. It renders if installed on the user's device; otherwise the browser uses a close monospace fallback. For guaranteed typography on every device, supply a properly licensed webfont later.
- Product images and scent descriptions are mockup/concept data, not product photography or verified formulation claims.
- Matches and journal are placeholders until details are approved.
